# Allow one reimbursement-gated Loan per Build

A Build may contain exactly one reimbursement-gated Loan, and every released canonical construction Draw posts its advance to that Loan. A Draw is never split through funding allocations across multiple reimbursement facilities. The Financing Package may still combine that construction Loan with upfront-funded and on-demand Loans. This preserves one construction-draw funding owner and one approval and release path while still supporting hybrid financing packages.
