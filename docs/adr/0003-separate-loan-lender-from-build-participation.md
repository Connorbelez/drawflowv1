# Separate Loan lenders from Build participation

Only the Primary Construction Lender becomes an operational participant in a Build Proposal and active Build. Each Proposed Loan and Loan identifies its own Loan Lender, and a non-primary Lender Organization may see its active Loans with a limited reference to the associated Build without receiving Build Workspace access; this supports multi-lender Financing Packages without leaking construction operations or treating every financing provider as the draw-governance lender.
