## Brand Kit

- Draft paper: `#FAF5EC`
- Pine ink: `#073C33`
- Steel blueprint: `#4D83B6`
- Terracotta: `#C9643E`
- Washed eucalyptus: `#D9E7D6`

## Folders

- `concept-sections/`: the eight generated horizontal section concepts, retained as visual implementation references.
- `images/`: reusable bitmap assets extracted/generated for the actual page build.
- `icons/`: deterministic SVG line icons for expertise, claims, and media controls.
- `patterns/`: SVG blueprint grid and paper grain backgrounds.
