# Fairlend Multiplex GTA Asset Pack

Route: `/multiplex-financing-gta`

This pack contains the discrete page assets for the Human-Scale-Housing plus
soft-brutalist direction. Each of the eight canonical page sections has exactly
one photographic asset. UI diagrams, section rails, stamps, grid texture, and
checklists should be rendered as code or SVG, not baked into the photos.

Primary manifest: `manifest.json`

## Directories

- `images/`: optimized WebP assets intended for route usage.
- `source/`: generated PNG sources preserved for future reprocessing.
- `patterns/`: reusable SVG background textures.
- `icons/`: reusable SVG marks and stamps.
- `contact-sheet.jpg`: quick visual QA sheet for the eight section photos.
