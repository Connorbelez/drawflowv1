# The cleanest structure is:

**Problem → Confusion → Stakes → Solution → Method → Outcome → CTA**

Not just **problem → solution**. For this section, the problem is not simply “builders need consulting.” The real problem is: **the old build equation no longer works, and builders do not know which version of the project still pencils.** That came through very clearly in the interview: land + construction + soft costs used to leave profit; now that same formula often produces losses unless the project, property, cost structure, and exit strategy are chosen correctly. 

## Recommended landing page structure

### 1. Section eyebrow

Small label above the headline.

**Builder Consulting**
or
**Multiplex & Infill Strategy**

This tells users what section they are in without making the headline boring.

---

### 2. Problem headline

Do **not** lead with “we offer consulting services.” Lead with the tension.

Strong options:

**The old build math stopped working.**

**Not every multiplex project pencils. We help you find the one that does.**

**Before you buy the lot, know if the numbers work.**

**The opportunity is real. The formula is different.**

My favourite for FairLend:

> **The old build math stopped working. We help you find the formula that still pencils.**

This ties directly to the founder’s interview: custom build economics changed, multiplexes can work, but only when the variables are structured correctly.

---

### 3. Problem body copy

This should be short and punchy. Explain the market shift.

Example:

> A few years ago, a builder could buy land, cover construction and soft costs, sell the finished home, and still have room for profit. Today, that equation often breaks.
>
> Multiplex, garden suite, and infill projects can still work — but only when the land, zoning, build size, unit mix, costs, exit strategy, and financing path are aligned from the beginning.

This frames the problem without sounding negative or alarmist.

---

### 4. Confusion block

This is where you should make the visitor feel seen. The interview repeatedly comes back to the builder’s uncertainty: *Where should I buy? What should I build? Should I rent or sell? How much can I pay for land?* 

Use a visual cluster of questions.

Example:

**You’re probably asking:**

| Decision   | Builder question                                                     |
| ---------- | -------------------------------------------------------------------- |
| Land       | What lot should I buy?                                               |
| Price      | How much can I afford to pay?                                        |
| Strategy   | Should I rent, sell, or condominiumize?                              |
| Density    | How many units should I build?                                       |
| Costs      | What cost per square foot keeps this profitable?                     |
| Financing  | Can this qualify for better takeout financing?                       |
| Incentives | Can MLI Select, HST, or development fee changes improve the numbers? |

This is the emotional hook. It turns the section from generic consulting into “FairLend understands exactly what I’m trying to figure out.”

---

### 5. Stakes / consequence

This is the “why it matters” layer.

Example:

> Choose the wrong property, overpay for land, build the wrong unit mix, or miss a financing incentive, and the project can move from profitable to underwater before construction even starts.

Keep this concise. You do not want fear-mongering, but you do want urgency.

---

### 6. Solution headline

Now introduce FairLend.

Options:

**FairLend helps you build the right equation before you build.**

**We help you turn a confusing project into a financeable plan.**

**From land decision to takeout strategy — we help model the path.**

Best version:

> **We help you build the equation before you build the project.**

That is sticky, founder-aligned, and visually extensible.

---

### 7. Solution body copy

Example:

> FairLend works with builders early — before the project is locked in — to assess the land, model the numbers, structure the financing, and identify the most practical path from acquisition to construction to takeout.

This should make it clear that consulting is not abstract advice. It is tied to financing execution.

---

### 8. “What we help with” grid

This is where you make the service tangible.

Use 4–6 cards:

**Land & Site Selection**
Lot size, neighbourhood, zoning potential, constraints, trees, servicing, and acquisition price.

**Build Strategy**
Purpose-built rental vs. condominium sale, unit count, unit size, density, and project positioning.

**Project Economics**
Land cost, construction cost, soft costs, projected value, rental income, sale proceeds, and financing costs.

**Construction Financing**
Draw structure, working capital, lender requirements, repayment plan, and build-stage capital.

**MLI Select & Takeout Planning**
Energy efficiency, affordability, accessibility, and long-term financing strategy.

**Exit Strategy**
Hold, sell, refinance, condominiumize, or transition into takeout financing.

---

### 9. Process section

This should be dead simple. In the interview, the rough flow was: consultation → build a plan → secure capital → construct/complete → takeout financing. Use that.

**How it works**

1. **Start with a consultation**
   Tell us what you want to build, where you’re looking, and what stage you’re at.

2. **Model the project**
   We help assess the land, costs, financing, unit strategy, and exit options.

3. **Build the financing plan**
   FairLend structures the mortgage, construction financing, draw plan, or takeout path.

4. **Move from plan to project**
   Build with a clearer financial roadmap and financing partner behind you.

5. **Plan the takeout**
   Where applicable, we help position the project for refinance, sale, or MLI Select takeout.

---

### 10. Outcome statement

This should be the “after” state.

Example:

> Instead of guessing what to buy, what to build, and how to finance it, you get a practical project plan built around the numbers.

Or more brandable:

> **Less guesswork. Better land decisions. Cleaner financing. A project that has a path to profit.**

---

### 11. CTA

Use a builder-specific CTA, not generic “contact us.”

Best options:

**Book a Builder Consultation**

**Model My Project**

**See If My Build Pencils**

**Start With the Numbers**

My pick:

> **See If Your Build Pencils**

That is more compelling than “Book a Consultation,” because it promises the first outcome.

---

## Visual concept

The visual should literally dramatize the problem → solution arc.

Before state:

```text
Land + Construction + Soft Costs > Project Value
Result: Red
```

Then show variables shifting:

```text
Lot Price
Unit Mix
Cost / Sq. Ft.
Rental Strategy
Condo Strategy
MLI Select
Takeout Financing
```

After state:

```text
Right Land + Right Build + Right Financing + Right Exit
Result: Black
```

I would avoid the slot-machine metaphor unless it is very subtle. It can feel cheap. A better FairLend version would be a **financial model / equation interface**: clean cards, dials, sliders, blueprint lines, and a red-to-black project outcome indicator.

## Strongest final positioning

Use this as the conceptual anchor:

> **Builders do not need more generic advice. They need to know which project, on which lot, at which price, with which financing path, actually works.**

That is the whole section.
