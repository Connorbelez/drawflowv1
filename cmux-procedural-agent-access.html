Procedural agent access

Every agent is a window.
One socket talks to all of them.

CMUX turns your terminal into a multiplexer where each pane is a live agent — regardless of harness. Claude Code, Codex, a raw shell: it doesn't matter what powers a pane. What matters is that CMUX exposes every surface over a single Unix-domain socket, so any one agent can discover the others, watch them, and send them work.

The orchestrator in the top-left pane doesn't need to know how the agent in the top-right pane thinks. It needs one thing: a way to see it and a way to talk to it. That's it — surface.list, surface.read_text, surface.send_text.

The protocol

Three calls to drive any agent

The CLI (cmux send --surface …) is sugar over the socket. If you want one process to procedurally orchestrate others, talk to the socket directly — same methods, no subprocess per call, holds the connection open.

A request is one newline-terminated JSON object. The response comes back with ok, a result, and (on failure) error: 

// request
{ "id":"req-1", "method":"surface.list", "params":{} }\n
// response
{ "id":"req-1", "ok":true,
  "result":{ "surfaces":[...] } }

Every agent in your workspace answers on the same socket. That's why harness doesn't matter — the panes are interchangeable, and the socket is the bus between them.

Method Does
surface.list Enumerate every surface (agent/pane) with its id, title & status — the orchestrator's eyes.
surface.read_text Read a surface's current screen / scrollback. confirm the top-right agent really is free before you task it.
surface.send_text Send a line of input (a prompt) to one surface — the orchestrator's hands.
surface.send_key Send a key (enter, ctrl-c…).
surface.focus Bring a surface to the foreground / focus it.
surface.move Relocate a surface to another pane/window/index.
workspace.create Spawn a new workspace at a cwd.
browser.eval Run JS in a webview surface if you have one.

Make it yours

A client in ~20 lines

#!/usr/bin/env python3
# orchestrator.py — one process drives every agent in the workspace
import json, socket, os, time

SOCKET = os.environ.get("CMUX_SOCKET_PATH", "/tmp/cmux.sock")

def rpc(method, params=None):
    with socket.socket(socket.AF_UNIX, socket.SOCK_STREAM) as s:
        s.connect(SOCKET)
        s.sendall(json.dumps(
            {"id": "r"+str(time.time()), "method": method,
             "params": params or {}}).encode() + b"\n")
        return json.loads(s.recv(65536).decode())["result"]

# 1 · discover — orchestator learns who is where (incl. the top-right pane)
panes = rpc("surface.list")["surfaces"]
scout  = next(p for p in panes if p["id"] == "surface:2")
print("saw", scout["title"], "→", scout["id"])

# 2 · watch — confirm it's idle before tasking
out = rpc("surface.read_text", {"surface_id": scout["id"], "scrollback": True})
print("screen:", out["text"][-80:])

# 3 · act — send it a prompt
rpc("surface.send_text", {"surface_id": scout["id"],
                              "text": "Scan the repro, find the failing test, report back.\n"})
Fewer methods than that if you prefer the bindings or the MCP wrapper — the socket is underneath all of them.

Two things that bite

Socket security. It's owner-only (0600), and the default mode rejects connections that lack cmux ancestry. An outside orchestrator is exactly that — so flip the socket mode to Automation (any local process, same user) before wiring cross-harness scripts, or your connections get refused.

Auth. If you've set password mode, send auth <password> before everything else. And note the legacy {"command":…} payload shape is gone — use method + params.

The payoff

Route work across harnesses for free

  • Claude Code teams — launch with cmux claude-teams; spawned teammates become native cmux splits with sidebar metadata & notifications.
  • Any other tool you drop in a pane is equally addressable by surface_id. One socket client drives them all.
  • Compose agents — orchestrator hands a task to the scout, reads the result, sends it to a reviewer, reads that back. No harness knows or cares about the others.

The CLI forms: cmux list-panels, cmux send --surface <id> "prompt", cmux send-key --surface <id> enter.

The bottom line: procedural access = open the socket, list the surfaces, read one, send one. That single socket is your universal message bus between agents of any harness.
